# Code of Conduct

Be respectful, specific, and constructive. Harassment, discrimination, threats, deliberate disclosure of private information, and sustained disruption are not acceptable in project spaces.

Report conduct concerns privately through the maintainer contact route described in the repository's GitHub security/advisory interface. Reports will be reviewed in context, kept as confidential as practical, and may result in content removal or temporary or permanent exclusion from project spaces.

This concise policy applies to issues, pull requests, discussions, and other spaces represented as part of the project.
