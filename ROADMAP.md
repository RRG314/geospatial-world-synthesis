# Roadmap

The 0.2 line concentrates on correctness and reproducibility for bounded JavaScript workflows. Work deliberately deferred beyond 0.2.0 includes independently reviewed multi-geography ground truth, chunked/streaming world assembly beyond the demonstrated 100k-per-source matcher workload, a Python bridge, GeoParquet and GeoPackage ingestion, CityJSON/3D semantics, topology repair, antimeridian splitting, deletion-feed semantics, and a production-validated PostGIS backend.

These are directions, not commitments. A capability moves into the supported matrix only after its implementation, tests, licensing/attribution review, user documentation, and clean-consumer validation agree.
